# QueueFuel

Fuel station queue management app for Iraq. Cross-platform Flutter application supporting Android, iOS, and Web.

## Tech Stack

- **Framework:** Flutter 3.16+
- **Language:** Dart 3.2+
- **State Management:** Riverpod (with code generation)
- **Navigation:** go_router
- **Backend:** Firebase (Auth, Firestore, Messaging, Storage)
- **Maps:** Google Maps Flutter
- **Architecture:** Clean Architecture (domain/data/presentation layers)

## Getting Started

### Prerequisites

- Flutter SDK >= 3.16.0
- Dart SDK >= 3.2.0
- Firebase CLI (`npm install -g firebase-tools`)
- FlutterFire CLI (`dart pub global activate flutterfire_cli`)
- Android Studio or Xcode (for platform builds)

### Setup

1. **Install dependencies:**
   ```bash
   flutter pub get
   ```

2. **Configure Firebase:**
   ```bash
   flutterfire configure --project=queue-6a58d
   ```
   This generates `lib/firebase_options.dart` with platform-specific Firebase configuration.

3. **Run code generation** (for Freezed models and Riverpod providers):
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```

4. **Run the app:**
   ```bash
   flutter run
   ```

### Platform-Specific Setup

#### Android
- Place `google-services.json` in `android/app/` (generated by FlutterFire CLI)
- Minimum SDK: 23 (Android 6.0)
- Target SDK: 34 (Android 14)

#### iOS
- Place `GoogleService-Info.plist` in `ios/Runner/` (generated by FlutterFire CLI)
- Minimum deployment target: iOS 14.0
- Run `cd ios && pod install` after adding new dependencies

#### Web
- Firebase SDK is loaded via script tags in `web/index.html`
- Configuration is injected by FlutterFire CLI

```
    theme/        - Material theme definitions
    utils/        - Utility functions

  presentation/

    widgets/      - Reusable widgets
```

## Key Domain Concepts

- **Roles:** USER, REPORTER, ADMIN
- **Queue Statuses:** EMPTY, SHORT, MODERATE, LONG, CLOSED
- **Geo Proximity:** 200m Haversine distance for station reports
- **Cycle Policy:** 5-hour reporting cycles
- **Status Expiry:** 40 minutes before queue status expires
- **Points System:** Gamification for accurate reports
